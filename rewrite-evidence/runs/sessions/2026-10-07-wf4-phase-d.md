## Highest-value findings (for the report)

1. **The crossover is measurable.** Syntax errors hide type errors (a file that
   doesn't parse can't be type-checked). The 0→5297 jump is not a regression; it
   is the first honest measurement of the semantic residual — the exact shape of
   evidence H2 needs. Histogram in tsc-burndown.md.
2. **The `.value` blanket-strip was nearly the workflow's first silent-wrong-code
   incident.** Domain objects legitimately have `.value` properties
   (QueryFilterBuilder choices). Codemod now strips only identifiers it converted
   itself; everything else stays as a VISIBLE TS2339 residual. This is the
   "plausible-but-wrong vs visible-and-fixable" trade-off, decided in favor of
   visible — and it is greppable evidence.
3. **`defineModel` + generic `defineEmits<{...}>`** turned out to carry the payload
   types the runtime forms lack — the codemod now emits typed `onX` props from
   them (addresses the gate-2 typing concern generically, not just in fixtures).
4. **Nuxt has THREE auto-import mechanisms, not one**: Vue APIs (unplugin), composables,
   AND components. The first two were indexed in Phase B/C; the component index was
   only discovered via the TS2304 family at scale (2081 occurrences). Fixture-scale
   work would never have found it — the samples all imported components explicitly.
